DSA Implementation Analysis

Detailed breakdown of algorithms and data structures applied at each pipeline stage.

FEATURE EXTRACTION

Data Structure
Hash Map / Frequency Matrix
Purpose
Count and organize document terms efficiently after stop-word removal.
Input
Raw Document Token Array
Output
Key-Value Pairs (Term → Count)
Complexity: O(N)

OPTIMIZATION

Algorithm
Timsort (Collections.sort) / Bounding
Purpose
Sort features by highest frequency and isolate the dominant term vector.
Input
Unordered Hash Map
Output
Truncated Sorted List
Complexity: O(K log K)

SIMILARITY

Algorithm
Jaccard Similarity
Purpose
Compare optimized feature sets via Intersection over Union ratio.
Input
Two Optimized Feature Sets
Output
Float Score [0.0 - 1.0]
Complexity: O(N * M)

GRAPH CONSTRUCTION

Data Structure
Adjacency List (Map<Node, List<Node>>)
Purpose
Represent relationships between similar documents linking edges above threshold.
Input
Documents & Threshold
Output
Undirected Graph
Complexity: O(V²)

TRAVERSAL & CATEGORIZATION

Algorithm
BFS (Queue) / DFS Connected Components
Purpose
Traverse the Adjacency List to group mutually similar disjoint components.
Input
Adjacency List
Output
List of Grouped Components
Complexity: O(V + E)
