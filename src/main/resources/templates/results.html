How Categories & Groupings Are Generated (Category-Independent DSA Pipeline)

Zero Hardcoded Topics

This system does not use predefined topic dictionaries, machine learning, or hardcoded if/else rules. Every category group and label is derived deterministically from the uploaded documents using a 5-stage algorithm:

1
Connected Component
BFS traverses the document graph () to isolate each maximal connected subgraph.
2
Aggregate Features
Each member document's Top 15 Merge-Sorted features are pooled and frequencies are summed across the component.
3
Rank Features
Pooled terms are sorted in descending order of total component frequency (with lexicographical A–Z tie-breaking).
4
Select Dominant (Top 3)
The top min(3, U) highest-frequency terms are selected as the component's dominant descriptors.
5
Generate Category Label
Selected dominant terms are title-cased and joined with " / " (or fallback "Undetermined" if 0 features exist).
